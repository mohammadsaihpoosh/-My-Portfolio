ABOUT
THIS DISC_

THIS IS NOT AN OFFICIAL PLAYSTATION ARCHIVE.

LOST GAMES is an experimental web tribute to the strange corners of early-2000s gaming culture: abandoned fan pages, obscure menus, scratched discs, corrupted save data and the atmosphere of games remembered imperfectly.

The titles and file records presented in this interface are fictional concepts created for the visual experience. The imagery is atmospheric placeholder photography, not proof of lost or unreleased PS2 games.
